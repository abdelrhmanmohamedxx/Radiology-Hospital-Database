Radiology HIS Phase 2 Website

How to run with XAMPP:
1. Install XAMPP.
2. Start Apache and MySQL.
3. Open phpMyAdmin: http://localhost/phpmyadmin
4. Import schema.sql, or run it in MySQL Workbench.
5. Copy this whole folder to: C:\xampp\htdocs\radiology_phase2_website
6. Open: http://localhost/radiology_phase2_website/index.php

Default login accounts:
patient1 / 12345
doctor1 / 12345
nurse1 / 12345
admin1 / 12345

If your MySQL root has a password, edit db.php and write the password.
